# 도서 검색 기능 명세

한입독서에서 읽을 책을 찾아 등록 정보를 채우는 동작의 기준입니다.
- **검색**(2장): 제목이나 저자로 책 목록을 찾아 판본을 고른다.
- **페이지 자동 채움**(3장): 고른 판본의 총 페이지 수를 가져와 페이지 설정 화면의 기본값으로 넣는다.

이 문서를 읽는 방법과 고치는 시점은 다음과 같습니다.
- **사용자 시나리오**로 의도한 흐름을 확인하고, **요구사항**으로 구현을 검증합니다.
- 검색 결과의 내용, 정렬, 페이지 자동 채움 규칙이 바뀔 때만 이 문서를 수정합니다. 검색 출처나 페이지 출처를 바꾸는 결정은 `history/decisions/`에 ADR로 남기고 이 문서의 출처 설명을 함께 고칩니다.

## 1. 용어

| 용어 | 뜻 |
|---|---|
| 검색어 | 사용자가 검색창에 입력한 문자열. 제목 일부, 저자 이름 등 자유 형식 |
| 검색 결과 | 검색어로 찾은 책 목록. 정확도순이며 최대 10건이다 |
| 판본 | 같은 제목이라도 출판사, 출간일, 표지가 다른 개별 간행물. ISBN-13으로 구분한다 |
| ISBN-13 | 판본을 식별하는 13자리 숫자. 검색 결과의 각 책이 가진다. 없을 수도 있다 |
| 검색 출처 | 검색 결과를 가져오는 외부 서비스. 현재는 카카오 책 검색이다 |
| 페이지 출처 | ISBN-13으로 총 페이지 수를 가져오는 외부 서비스. 현재는 국립중앙도서관 ISBN 서지정보다 |
| 총 페이지 수 | 판본의 마지막 쪽 번호. 페이지 설정 화면에서 "총 N쪽" 기본값으로 쓴다 |
| 선택한 책 | 검색 결과에서 사용자가 탭해 고른 한 권. 한 번에 한 권만 선택된다 |
| 기본 표지 | 표지 이미지가 없거나 불러오지 못했을 때 대신 보여주는 단색 영역 |
| 설정 안내 알림 | 검색 기능에 필요한 설정이 빠져 있음을 알리는 확인 버튼 하나짜리 경고창 |

## 2. 검색

### 2.1 사용자 시나리오

**S1. 제목 일부로 원하는 책을 찾는다**
1. 사용자가 책 등록 흐름의 검색 화면에서 "소년이"를 입력하고 검색 버튼을 누르거나 키보드의 검색을 누른다.
2. 정확도순 검색 결과가 목록으로 보인다. "소년이 온다"가 상단에 있다.
3. 각 항목은 표지, 제목, 저자, 출간 연도, 출판사를 보여준다.

관련: A1, A2, A4, A5

**S2. 같은 제목의 여러 판본 중 하나를 고른다**
1. 사용자가 "데미안"을 검색한다.
2. 출판사와 출간 연도가 다른 여러 판본이 나열된다.
3. 사용자가 읽을 판본을 탭하면 그 항목만 선택 상태가 되고, 상단의 "완료" 버튼이 활성화된다.
4. 다른 항목을 탭하면 선택이 옮겨 간다.

관련: A3, A6, A7

**S3. 검색 결과가 없다**
1. 사용자가 존재하지 않는 제목을 검색한다.
2. 목록이 비어 있고 "완료" 버튼은 비활성 상태다.
3. 검색어를 고쳐 다시 검색할 수 있다.

관련: A6, A8

**S4. 네트워크 오류가 난다**
1. 기기가 오프라인이거나 검색 출처가 응답하지 않는다.
2. 검색 결과는 바뀌지 않고, 이전 결과가 있으면 그대로 남는다.
3. 사용자는 다시 검색할 수 있다.

관련: A9

**S5. 검색 설정이 빠져 있다**
1. 검색 출처에 필요한 인증 정보가 앱에 들어 있지 않은 빌드에서 검색한다.
2. 설정 안내 알림이 뜬다. 확인을 누르면 닫힌다.

관련: A10

### 2.2 요구사항

검색 실행
- **A1.** 검색은 검색 버튼 또는 키보드의 검색 동작으로 실행한다. 입력 중에는 자동으로 검색하지 않는다.
- **A12.** 검색어의 앞뒤 공백을 지운 결과가 비어 있으면 검색하지 않고 검색 결과도 바꾸지 않는다.
- **A2.** 검색 결과는 검색 출처의 정확도순 상위 10건이다. 앱에서 다시 정렬하거나 거르지 않는다.
- **A3.** 검색 결과에는 종이책과 전자책이 함께 나올 수 있다. 검색 단계에서 전자책을 구분하거나 제외하지 않는다.

검색 결과 항목
- **A4.** 각 항목은 제목, 저자, 표지 이미지 주소, 출판사, 출간일, ISBN-13을 가진다. 출간일은 날짜 값이며, 표지 이미지 주소·출간일·ISBN-13은 비어 있을 수 있다. 검색 출처가 주는 원래 형식(날짜 문자열, ISBN 묶음 등)은 항목에 남기지 않는다.
- **A5.** 목록의 각 항목은 표지, 제목, "저자 | 출간 연도 | 출판사" 한 줄을 보여준다. 저자에서 괄호 안 내용은 지운다. 출간 연도는 출간일에서 뽑는다. 검색 출처가 출간일을 주지 않거나 날짜로 해석할 수 없으면 출간일은 비어 있고, 연도 자리는 비워서 "저자 | 출판사"로 보여준다.
- **A6.** 표지 이미지 주소가 없거나 이미지를 불러오지 못하면 기본 표지를 보여준다. 그래도 그 항목을 선택하고 등록할 수 있다.
- **A11.** 검색 출처가 ISBN-10과 ISBN-13을 함께 주면 13자리만 ISBN-13으로 쓴다. 13자리가 없으면 ISBN-13은 빈 값이다.

선택
- **A7.** 항목을 탭하면 그 항목이 선택한 책이 되고, 이전 선택은 해제된다. 선택한 책이 있을 때만 "완료" 버튼이 활성화된다.
- **A8.** 새로 검색하면 검색 결과가 교체된다. 선택한 책이 새 결과에 없어도 선택은 유지되며, "완료"를 누르면 그 책으로 진행한다.

오류
- **A9.** 검색 출처의 네트워크 오류, 비정상 응답, 2xx가 아닌 상태 코드에서는 검색 결과를 바꾸지 않고 사용자에게 별도 안내를 하지 않는다.
- **A10.** 검색 출처의 인증 정보가 빌드에 없거나 자리표시자 그대로이면 설정 안내 알림을 띄운다. 알림 문구는 빠진 설정의 이름을 포함한다.

## 3. 페이지 자동 채움

### 3.1 사용자 시나리오

**S6. 페이지 수가 자동으로 채워진다**
1. 사용자가 "불편한 편의점"(2021, 나무옆의자)을 선택하고 "완료"를 누른다.
2. "완료" 버튼이 잠시 비활성화되고, 페이지 출처에서 총 페이지 수를 가져온다.
3. 페이지 설정 화면으로 넘어가며 "총 267쪽"이 기본값으로 들어 있다.
4. 사용자는 값을 그대로 쓰거나 고칠 수 있다.

관련: B1, B2, B3, B6

**S7. 페이지 수를 가져오지 못한다**
1. 사용자가 페이지 출처에 없거나 페이지 정보가 비어 있는 판본을 선택하고 "완료"를 누른다.
2. 페이지 설정 화면으로 넘어가며 총 페이지 수가 0으로 들어 있다.
3. 사용자가 직접 입력한다. 0인 채로는 다음 단계로 갈 수 없다.

관련: B4, B5, B7

**S8. 오프라인에서 "완료"를 누른다**
1. 검색은 됐지만 "완료"를 누르는 시점에 네트워크가 끊겼다.
2. 페이지 설정 화면으로 넘어가며 총 페이지 수는 0이다. 오류 안내는 없다.

관련: B7

### 3.2 요구사항

조회 시점
- **B1.** 총 페이지 수는 "완료"를 누른 시점에 선택한 책의 ISBN-13으로 한 번 조회한다. 검색 결과를 보여주는 단계에서는 조회하지 않는다.
- **B2.** 조회하는 동안 "완료" 버튼은 비활성화되고, 같은 조회를 중복으로 시작하지 않는다.
- **B3.** 조회가 끝나면 결과와 관계없이 페이지 설정 화면으로 넘어간다. 총 페이지 수는 그 화면의 "총 N쪽" 기본값이 된다.

값 해석
- **B4.** 페이지 출처에서 전자책이 아닌 기록만 조회한다. 전자책 기록의 페이지 값은 쓰지 않으며, 선택한 책이 전자책이면 기록이 없는 것과 같이 B7을 따른다.
- **B5.** 페이지 출처의 페이지 값은 자유 형식 문자열이다. 문자열에서 처음 나오는 아라비아 숫자 묶음을 총 페이지 수로 쓴다.

  | 페이지 값 | 총 페이지 수 |
  |---|---|
  | `332` | 332 |
  | `784 p.` | 784 |
  | `[130] p.` | 130 |
  | `252, 64 p.` | 252 |
  | `xiii, 345 p.` | 345 |
  | `230페이지 내외` | 230 |
  | 빈 문자열 | 0 |

- **B6.** 숫자 묶음이 없거나 0이면 총 페이지 수는 0이다.

생략과 오류
- **B7.** 다음 경우 조회를 생략하거나 실패로 보고, 총 페이지 수를 0으로 하며 사용자에게 안내하지 않는다.
  - 선택한 책의 ISBN-13이 비어 있다.
  - 페이지 출처에 해당 ISBN-13 기록이 없다.
  - 네트워크 오류, 비정상 응답, 2xx가 아닌 상태 코드.
  - 페이지 출처의 인증 정보가 빌드에 없거나 자리표시자 그대로다.
- **B8.** 페이지 설정 화면은 총 페이지 수가 0이거나 시작 쪽보다 작으면 다음 단계로 보내지 않고 안내 문구를 띄운다. 이 규칙은 자동 채움 여부와 관계없이 같다.

## 4. 등록 정보 보관

- **C1.** 검색으로 등록한 책은 제목, 저자, 표지 이미지 주소, 사용자가 확정한 총 페이지 수와 함께 ISBN-13을 보관한다. ISBN-13이 비어 있으면 비어 있는 채로 보관한다.
- **C2.** 표지는 이미지 주소만 보관하고 이미지 파일은 보관하지 않는다. 주소가 더 이상 유효하지 않으면 서재 화면에서 기본 표지를 보여준다.
