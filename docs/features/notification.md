# 알림 기능 명세

한입독서가 보내는 알림의 동작 기준입니다.
- **공통 규칙**(2장): OS 알림 권한, 앱 내 알림 설정, OS 알림 꺼짐 배너. 앱의 모든 알림에 적용됩니다.
- **알림 종류별 규칙**(3장~): 각 알림이 언제, 무엇을 보내는지. 현재 알림 종류는 **독서 알림** 하나입니다.

이 문서를 읽는 방법과 고치는 시점은 다음과 같습니다.
- **사용자 시나리오**로 의도한 흐름을 확인하고, **요구사항**으로 구현을 검증합니다.
- 알림과 관련된 기능 동작이 바뀔 때만 이 문서를 수정합니다. 새 알림 종류는 3장과 같은 형식의 장으로 추가하고, 공통 규칙을 따릅니다.

## 1. 용어

| 용어 | 뜻 |
|---|---|
| 앱 내 알림 설정 | 받음 / 끔. 기본값 "받음". 알림 설정 화면의 "알림 끄기" 스위치로만 바꾼다. 앱의 모든 알림에 적용된다 |
| "알림 끄기" 스위치 | 켜면(초록) "끔", 끄면(회색) "받음". 기본은 회색 |
| OS 알림 권한 | 미결정 / 허용 / 거절. 기본값 "미결정". 최초 1회 OS 팝업으로 정하고, 거절 후에는 iOS 설정 앱에서만 바꾼다 |
| OS 팝업 | iOS의 알림 권한 요청 창. iOS가 앱마다 한 번만 띄우며, 앱의 안내 화면 없이 바로 띄운다. 이미 결정된 뒤에는 요청해도 팝업 없이 결과만 돌아온다 |
| OS 알림 꺼짐 배너 | 앱 내 알림 설정은 "받음"인데 OS 알림 권한이 "거절"이라 알림이 오지 않음을 알려주는 안내. 알림 설정 화면 상단에 "기기의 알림 설정이 꺼져 있어요!"로 표시하고, 탭하면 iOS 설정 앱의 이 앱 설정 화면으로 이동한다 |
| 독서 알림 | 읽는 책의 독서 계획에 맞춰 보내는 알림. 아침 리마인드 알림과 자정 미완료 알림으로 이루어진다 |
| 알림 대상 책 | 독서 알림을 보내는 책. 읽는 책 중 가장 최근에 등록한 책 한 권이다 |
| 다음 독서일 | `max(마지막 독서일, 오늘)` 당일을 포함해, 아직 기록하지 않은 가장 이른 독서 계획일. 하루의 경계는 기기 시간대 기준 새벽 4시다 |

## 2. 공통 규칙

알림은 **앱 내 알림 설정이 "받음"이고 OS 알림 권한이 "허용"일 때만** 등록됩니다.

### 2.1 사용자 시나리오

#### OS 알림 권한

OS 팝업은 두 시점에만 뜹니다. 알림 설정 화면에 들어올 때(S1)와 처음 책을 등록할 때(S5)입니다. 앱 내 알림 설정은 알림 설정 화면에서만 바꿀 수 있고 그 화면에 들어오면 먼저 권한을 묻기 때문에, 그 밖의 시점에는 권한이 이미 정해져 있습니다.

**S1. 책을 등록하기 전에 알림 설정 화면에 들어간다**
1. 사용자가 책을 등록하지 않은 채 알림 설정 화면에 들어간다.
2. 앱 내 알림 설정이 "받음"이고 아직 권한을 묻지 않았으므로 OS 팝업이 뜬다.
3. 허용하면 배너 없이 화면을 쓴다. 거절하면 상단에 OS 알림 꺼짐 배너가 보인다.
4. 이미 권한을 정했다면 팝업 없이 현재 상태만 보여준다.

관련: C2, C3, C6

**S2. 거절했다가 다시 알림을 받고 싶다**
1. 사용자가 알림 설정 화면에 들어가면 상단에 OS 알림 꺼짐 배너가 보인다.
2. 배너를 탭하면 iOS 설정 앱의 이 앱 설정 화면으로 이동한다.
3. 사용자가 그곳에서 알림을 허용하고 앱으로 돌아오면 배너가 사라진다.
4. 그 자리에서 바로 각 알림 종류의 규칙에 따라 알림이 예약된다.

관련: C4, C6, C7, D2

#### 앱 내 알림 설정

**S3. 알림을 끈다**
1. 사용자가 알림 설정 화면에서 "알림 끄기" 스위치를 켠다.
2. 예약된 알림이 종류와 관계없이 모두 지워진다.
3. 이후 어떤 화면에서도 알림이 예약되지 않고 OS 팝업도 뜨지 않는다.
4. OS 알림 권한이 거절 상태여도 OS 알림 꺼짐 배너를 보여주지 않는다. 사용자가 직접 끈 상태이기 때문이다.

관련: C1, C5, C6, C9

**S4. 끈 알림을 다시 켠다**
1. 사용자가 "알림 끄기" 스위치를 끈다.
2. 각 알림 종류의 규칙에 따라 알림이 다시 예약된다.
3. 등록할 알림이 없으면 설정만 저장된다.
4. OS 알림 권한이 거절 상태라면 상단에 OS 알림 꺼짐 배너가 보인다(S2로 이어짐).

관련: C5, C6, C8, D2

### 2.2 상태 한눈에 보기

| 앱 내 알림 설정 | OS 알림 권한 | 알림 등록 | OS 알림 꺼짐 배너 |
|---|---|---|---|
| 받음 | 미결정 | 안 함 (권한을 묻는 시점에 결정) | 숨김 |
| 받음 | 허용 | **등록** (알림 종류별 등록 조건을 충족할 때) | 숨김 |
| 받음 | 거절 | 안 함 | **표시** |
| 끔 | 미결정 | — (생기지 않음. 끄려면 알림 설정 화면에 들어와야 하고, 들어올 때 권한을 먼저 묻는다) | — |
| 끔 | 허용 | 안 함 | 숨김 |
| 끔 | 거절 | 안 함 | 숨김 |

### 2.3 요구사항

권한 요청
- **C1.** OS 팝업은 알림 설정 화면 진입(C2)과 첫 책 등록(D3) 두 시점에만 뜬다. 그 밖의 등록 경로에서는 권한이 이미 정해져 있다.
- **C2.** "받음"이고 권한이 미결정일 때 알림 설정 화면에 들어오면, 등록할 알림이 없어도 OS 팝업이 1회 뜨고 그 결과로 배너를 갱신한다.
- **C3.** 알림 설정 화면 진입 시 권한이 이미 결정됐으면 상태 조회만 한다.
- **C4.** 알림 설정 화면에서 iOS 설정 앱으로 나갔다가 돌아오면 권한을 요청하지 않고 상태만 조회해 배너를 갱신한다. 이때 "받음"이고 권한이 허용이면 각 알림 종류의 등록 규칙에 따라 알림을 다시 등록한다.

알림 설정 화면
- **C5.** "알림 끄기" 스위치를 켜면 앱 내 알림 설정은 "끔", 끄면 "받음"이다. 스위치 설명은 "한입독서와 관련된 알림 수신이 중단돼요"이다.
- **C6.** OS 알림 꺼짐 배너는 화면 상단에 표시하며, "받음"이고 권한이 거절일 때만 보인다. 미결정·허용이거나 "끔"이면 숨긴다.
- **C7.** OS 알림 꺼짐 배너를 탭하면 iOS 설정 앱의 이 앱 설정 화면으로 이동한다.
- **C8.** "받음"으로 바꾸면 각 알림 종류의 등록 규칙에 따라 알림을 다시 등록한다. 등록할 알림이 없으면 설정값만 저장한다.
- **C9.** "끔"으로 바꾸면 읽는 책 유무와 관계없이 대기 중인 알림을 종류와 관계없이 모두 제거하고, 권한을 요청하지 않는다.
- **C10.** 알림 설정 화면이 저장된 값을 불러오는 것만으로는 저장, 알림 등록, 권한 요청이 일어나지 않는다.

등록 조건
- **C11.** 알림은 "받음"이고 권한이 허용일 때만 등록한다. 권한 요청 결과를 기다리는 동안 "끔"으로 바뀌면 등록하지 않는다.
- **C12.** 권한이 거절이면 어떤 등록 경로에서도 등록을 건너뛰고, 등록 실패를 따로 알리거나 OS 팝업을 다시 띄우지 않는다. OS 알림 꺼짐 배너는 C6을 따른다.
- **C13.** 한 알림 종류를 다시 등록할 때는 그 종류의 기존 알림만 지우고 다른 종류의 알림은 남긴다. 등록 직전에 C11 조건을 다시 확인한다.

## 3. 독서 알림

알림 대상 책의 다음 독서일에 맞춰 아침 리마인드 알림과 자정 미완료 알림을 보내 독서 습관을 돕습니다. 읽는 책이 여러 권이어도 알림은 알림 대상 책 한 권에만 보냅니다.

| 알림 | 보내는 시각 | 내용 |
|---|---|---|
| 아침 리마인드 알림 | 다음 독서일의 리마인드 시간 (기본 09:00) | 그날 읽을 쪽수 등 독서 시작 안내 |
| 자정 미완료 알림 | 다음 독서일 다음 날 00:00 | 그날 기록하지 않았음을 알림 |

### 3.1 사용자 시나리오

**S5. 처음 책을 등록한다 (권한을 묻는 주 경로)**
1. 사용자가 앱을 설치하고 읽을 책을 등록한다. 앱 내 알림 설정은 기본값 "받음"이다.
2. 등록을 마치면 OS 팝업이 뜬다.
3. **허용**하면 다음 독서일의 아침 리마인드 알림과 자정 미완료 알림이 예약된다.
4. **거절**해도 책 등록은 정상으로 끝나고, 알림만 예약되지 않는다. 오류 안내는 없다.

관련: D1, D2, D3, C11, C12

**S6. 리마인드 시간을 바꾼다**
1. 사용자가 알림 설정 화면에서 리마인드 시간을 누르면 시간 선택기가 열린다. 기본값은 오전 9:00이고, 04:00~23:55 사이를 5분 단위로 고른다.
2. "받음" 상태이고 읽는 책이 있으면 아침 리마인드 알림이 새 시간으로 다시 예약된다.
3. "끔" 상태이거나 읽는 책이 없으면 시간만 저장된다.

관련: D4, D5

**S7. 매일 독서한다**
1. 다음 독서일 아침, 리마인드 시간에 "오늘 목표는 N쪽이에요!" 같은 알림이 온다.
2. 사용자가 그날 기록하면 알림이 다음 독서일로 다시 예약된다.
3. 그날 기록하지 않으면 자정(다음 날 00:00)에 미완료 알림이 온다.

관련: D6~D9

### 3.2 요구사항

등록
- **D1.** 독서 알림은 알림 대상 책 한 권에 대해 아침 리마인드 1개, 자정 미완료 1개만 예약하며, 식별자는 `{bookId}-morning`, `{bookId}-night`이다. 다른 책의 독서 알림은 남기지 않는다.
- **D2.** 책 등록, 홈 진입, 독서 기록, 독서 계획 변경(기간 연장 포함), "받음"으로 전환(C8), iOS 설정 앱에서 복귀(C4) 시 알림 대상 책의 독서 알림을 다시 등록한다. 읽는 책이 없으면 등록하지 않는다.
- **D3.** "받음"이고 권한이 미결정일 때 책을 등록하면 OS 팝업이 1회 뜬다.
- **D10.** 읽는 책을 삭제하거나 완독하면, 남은 읽는 책이 있을 때 그중 알림 대상 책으로 다시 등록하고, 없으면 독서 알림을 모두 제거한다.

리마인드 시간
- **D4.** 리마인드 시간은 기본 09:00이고, 04:00~23:55 범위에서 5분 간격으로 고른다.
- **D5.** "끔"이거나 읽는 책이 없으면 시간을 바꿔도 시간만 저장한다. "받음"이고 읽는 책이 있으면 아침 리마인드 알림만 다시 등록한다.

스케줄과 문구
- **D6.** 알림 날짜는 다음 독서일(1장 정의)이다. 다음 독서일이 없으면 알림을 만들지 않는다.
- **D7.** 아침 리마인드 알림은 다음 독서일의 리마인드 시간에 보낸다.
- **D8.** 자정 미완료 알림은 다음 독서일 다음 날 00:00에 보낸다. 그날 기록하면 다음 독서일로 다시 예약되므로, 결과적으로 그날 기록하지 않았을 때만 울린다.
- **D9.** 아침 리마인드 알림 제목은 그날 읽을 쪽수를 포함할 수 있다. 쪽수는 시작 쪽부터 목표 종료 쪽까지(양 끝 포함)의 쪽수를 오늘부터 목표 종료일까지의 독서일 수로 나눈 몫(소수점 이하 버림)이다. 시작 쪽은 기록 중 가장 많이 읽은 쪽의 다음 쪽이고, 기록이 없으면 마지막으로 읽은 쪽의 다음 쪽이며, 책의 시작 쪽과 목표 종료 쪽 사이로 제한한다. 계산할 수 없으면 1쪽으로 한다.
